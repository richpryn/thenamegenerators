Using elements to make a name

Most early Germanic names, including Old English and Old Norse ones, join two elements: a first part such as æþel 'noble' or Þór 'Thor', and a second such as wulf 'wolf' or steinn 'stone'. Place names add a description to a landscape word, so a ford, a hill or a farm gets a name from who owned it or what grew there.

To build your own, pick elements from one language, so the name sounds of a piece, and check the forms column for how a word changes inside a name. A name you build this way is built from real parts, not recorded, unless you find it in the sources. Our guide to prefixes and suffixes explains the patterns, and the Name Builder joins elements for you.

Frequently Asked Questions

+What is a name element?

A name element is a word or word part that names are built from. Old English names usually join two of them, so Æthelwulf is æþel 'noble' plus wulf 'wolf'. Place names work the same way: Oxford is 'ford used by oxen'.

+If I join two elements, is the result a real historical name?

Not necessarily. A pair of genuine elements makes a name that is built from real parts, but unless it turns up in the records it was never actually used. Our Library labels names like that as Built from real parts, not Recorded.

+Why do some elements say Uncertain?

Scholars don't always agree on what an old word meant, or whether a name really contains it. Where they disagree we say so, rather than pick the most exciting meaning.

+Do names mean what their elements mean?

Rarely in a literal way. Early names were often made by passing elements down a family, so a child called Wulfstan was not thought of as a 'wolf stone'. The meaning tells you where the parts came from, not what the parents intended.
