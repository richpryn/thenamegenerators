# Naming Library drafts

Researched drafts waiting for the content session's edit and fact check. The build
ignores this folder. To publish a page, edit it, then move it into `content/reference/`
(the build validates it there: sources, status labels, generator keys).

Citations in sections are `<sup><a href="#src-N">[N]</a></sup>`, numbered in the order
of the page's `sources` list, so keep the numbers in step if you reorder sources.

Notes from the researcher are in the Generator Builder's message of 12 Nov.
