# Minecraft cluster: long-tail searches

The Minecraft hub (`categories/minecraft-names.html`) and its generators, with the searches each page targets. The searches come from competitor pages, People Also Ask-style questions and the way Minecraft players phrase things. No search-volume tool was available, so the order within each list is a best guess; check Search Console after a few weeks and give the pages that pick up impressions more depth first.

Rules for every page: no Mojang canon names in the generators (Steve, Alex, Herobrine, Notch, Jeb, Dinnerbone, Grumm), but the name-tag Easter eggs are good FAQ material (see below).
