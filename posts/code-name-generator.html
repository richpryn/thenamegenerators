A good code name sounds like something and means nothing: a bird, a stone, a bit of weather or an old piece of kit. This code name generator makes them for spies and agents, military-style operations, work and software projects, NATO-style call signs and young secret agents, and leaves out the famous ones.

How code names work

A code name has one job: to let people talk about something without telling an eavesdropper what it is. So the best ones are ordinary words with no link to the real thing. A project to replace the office printers should not be called Project Ink.

In a 1943 note usually credited to Winston Churchill, wartime planners were told to avoid boastful or silly operation names, because no family should hear that their son was lost in an operation called "Bunnyhug" or "Ballyhoo". British operation names are still meant to give nothing away, which is why so many are single, slightly old-fashioned words.

Software and product teams borrowed the habit. Their code names keep a release secret until launch and give a project a name before the marketing team has chosen the real one. Many teams pick a theme (birds, stones, spices) and work through it, which is what the Project and One word styles here do.

Call signs and the NATO alphabet

The NATO spelling alphabet (Alpha, Bravo, Charlie and so on) was adopted in 1956 so that letters could be read out clearly over a crackly radio. Call signs join a letter word to a number: Echo Seven, Sierra Three, Tango Seven-Eight. The official spellings are actually Alfa and Juliett, so that people who don't speak English say them correctly; this generator uses the everyday spellings.

Two letter words together can spell out an abbreviation by accident, and some of those are rude, so the NATO style here always pairs one letter word with numbers.

Choosing one that works

  • Say it out loud. A code name gets shouted across rooms and typed into chats. If you have to spell it twice, pick another.
  • Keep it unconnected. If people can guess the secret from the name, it is a label, not a code name.
  • Avoid famous ones. Overlord, Market Garden and Desert Storm already belong to history, and fictional agents belong to their films. The generator leaves them out.
  • For a game or story, give the code name a reason: who chose it, and what they were thinking about that day.
  • For a real product, a code name is usually internal. If it might end up on a website or a box, check it isn't already a product or a trade mark first.

Frequently Asked Questions

+What is a good code name for a spy?
Something short and ordinary with no link to the person, like Agent Nightjar, Glass Needle or Halcyon. Choose Spy or agent for names in that style.
+How do I make an operation name?
Use "Operation" with one unusual word or an adjective and a noun: Operation Rookery or Operation Northern Drawbridge. Choose Operation for a list of them.
+What is a good code name for a work or software project?
A friendly word from one theme, like Project Bluebell or Project Lighthouse, that people won't mind saying in meetings. Choose Project, and keep the name inside the team until the real name is chosen.
+What are some cool one-word code names?
Old or unusual words work best: Tinderbox, Monolith, Halcyon, Undertow or Nightfall. Choose One word.
+How do NATO-style call signs work?
They join a word from the NATO spelling alphabet to a number, like Echo Seven or Tango Seven-Eight. Choose NATO style.
+What are some secret agent names for kids?
Silly ones are the most fun: Agent Pickle, Special Agent Noodle or Agent Wobbly Marshmallow. Choose Kids' agent.
+Are these real military code names?
No. They are new names built in the same style. Famous real operations and well-known fictional agents are left out on purpose.
