How the Discord Server Name Generator Works

It works from 728 names and name parts, which combine into over 14,000 possible results.

The choices:

  • Kind of server: Any kind, Gaming, Friends, Study, Art, Music, Anime, Roleplay, Fan community, Aesthetic, From a word.
  • Your word or name: type a name and it's built into every result (leave it blank to get "Pixel").

Where the names come from: Every name is invented. Names are built from gaming, study, art, music and anime words, cosy places and in-jokes, in the styles real servers use. Names from games, anime, TV shows and brands were left out, and nothing here is connected to Discord Inc.

Each press gives you 8 names. "Show 8 more" adds 8 you haven't seen yet. Once you've seen them all, "Start again" shuffles the whole list again.

A server name is the first thing people see in their sidebar and on an invite, so it should say what goes on inside. This Discord server name generator makes names for gaming groups, friends, study rooms, art and music servers, anime fans, roleplay worlds and fan communities, or builds one from your own word. It's an independent site and isn't connected to Discord Inc., which owns the Discord name.

What makes a good server name

The best server names do one of two jobs. Some say exactly what the server is for, so a stranger with an invite knows whether to join: Past Paper Club, Commission Corner, Clearwater City RP. Others are in-jokes for a group that already knows each other: Biscuit Tin Friends, Bad Ideas Committee. Public servers need the first kind; private ones can be as silly as you like.

Discord allows server names of 2 to 100 characters, but the sidebar and invite cards cut long names short, so the first two or three words do most of the work. Emoji and symbols are allowed, which is where aesthetic names like ✿ honey haven ✿ come from. You can change the name at any time in Server Settings, under Overview, if you have permission to manage the server.

Naming by kind of server

  • Gaming: game words that every player knows, like respawn, side quest, save point and boss fight. Avoid the name of one game unless the whole server is about it, and even then leave the game's logo and trade marks alone.
  • Study: be honest about the mood. Exam Season Survivors and The Night Before the Exam tell people it's friendly; Silent Study Hall tells them to keep their mic off.
  • Roleplay: a place name with an ending like -mere, -vale or -haven sounds like a world. Add RP, Academy or Kingdom of so people know it's a roleplay server.
  • Fan communities: name the fans, not the thing they love: Lore Keepers or Theory Crafters works for any show, book or creator, and keeps you clear of other people's trade marks.

Before you send the invite

The names here are free to use. Two servers can share a name, so there's nothing to register, but if the server might grow into a brand, a channel or a shop, search for the name first and check nobody else is using it for the same thing. For a matching handle, try the Gamertag Generator, and for a Minecraft server try the Minecraft Server Name Generator.

Frequently Asked Questions

+What is a good name for a Discord server?
One that says what the server is for in two or three words, like Respawn Lounge for gaming or Lo-fi and Laptops for study. Choose the kind of server for names that fit it.
+What are some funny Discord server names for friends?
In-jokes work best: We Share One Brain Cell, The Biscuit Committee or Unhinged but Lovely. Choose Friends for more.
+How do I make an aesthetic Discord server name?
Use two soft lowercase words and frame them with symbols, like ✿ honey haven ✿ or ☾ lilac daydream ☽. Choose Aesthetic.
+What should I call a roleplay server?
Something that sounds like a place, like Kingdom of Ashvale or Clearwater City RP. Choose Roleplay for fantasy realms, academies and city servers.
+How long can a Discord server name be?
Between 2 and 100 characters, according to Discord's developer documentation. Shorter names read better in the sidebar.
+Can I make a server name from my own name or a word?
Yes. Type it into the box and choose From a word to get names like Pixel Hangout or The Pixel Lounge.
+Is this an official Discord tool?
No. This is an independent name generator and isn't connected to Discord Inc.
