How the Name Combiner Works

Type two names and it joins the start of one to the end of the other, at points where the join reads naturally: a vowel meeting a consonant, with a vowel kept on each side. It skips results that just repeat one of the names, keeps the best-sounding ten (closest to the names' average length), and gives them to you in a random order. Very short names are also simply joined end to end.

For example, Romeo and Juliet give Juleo, Romuliet, Julimeo. Only the first word of each box is used.

Fans have been blending names for years: Ron and Hermione become Romione, and the press turned Ben Affleck and Jennifer Lopez into Bennifer. This name combiner does the same with any two names you type, as a ship name for a couple or characters, a joint name for a wedding hashtag, or a starting point for a baby name made from both parents' names.

How a good ship name works

The best blends keep the start of one name and the end of the other, joined where the sounds flow: Ron + Hermione keeps "Ro" and "mione" for Romione. Joins that put a vowel next to a consonant read naturally; two vowels or three consonants in a row usually trip the tongue.

Every pair gives a different set of blends, and the order of the names matters: try them both ways round. The generator already does, but a blend that starts with the other name often feels like a different couple.

Uses for a combined name

  • Ship names for fictional couples, in fan fiction, fan art and forums.
  • Couple names for wedding hashtags, joint social accounts or a shared house name.
  • Baby names: a blend of both parents' names can be a starting point. Check the result is a name you'd actually like to call across a playground.
  • Business or band names for two founders or two members.

Tips for better blends

  • Try nicknames. Sam and Alex give different blends from Samuel and Alexandra.
  • Say it out loud. A blend that looks good can sound odd, and the other way round.
  • Check what it spells. Some blends turn into real words, occasionally unfortunate ones.

Frequently Asked Questions

How do you make a ship name?

Take the start of one name and the end of the other, joined where the sounds flow: Ron + Hermione = Romione. Type two names into the combiner to see the options.

Can I combine two names for a baby name?

Yes: type both parents' names and look for a blend you like, or use it as inspiration for a real name with a similar sound.

Does it work with any names?

Yes, with any two names or words. It uses the first word of each box, and very short names are also simply joined end to end.
