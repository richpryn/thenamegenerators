## Start here

At the start of every session: read this file and docs/HANDOVER.md, run git status and git log -15, and list this site's open jobs on Site Jobs (ArtifactData query on https://claude.ai/artifact/9cukbteXbK5sJbHyxGHPri, collection tasks, where site == "tng" and done == false). Then say in two lines where things stand.

- Build: `node scripts/validate-data.js` (must be 0 errors), then `node scripts/build-pages.js`. Generators are `content/generators/<key>.json`; hubs `content/categories.json`; drawings `content/illustrations.json` (drawings: see the design notes in docs/HANDOVER.md). Guides `content/guides/`, Naming Library `content/reference/` (README there), name lists `content/lists/` (README there).
- Generator house rules: 200+ different names for every filter combination (`node scripts/capacity.js <key> 200`; the validator also fails any reachable combination that gives no names); "any" option first; option labels under 30 characters and every bracketed example a real output; `noEcho: true`; British English; family friendly, nothing rude in British English; no canon, brand or real famous names, checked against a ban list on every output; real-language meanings only when sure; read 60+ samples before shipping; build drafts in a staging folder, never half-written files on main.
- Business pages (`"checkName": true`, biz_* hubs): names a real business could use (easy to say and spell, says what it does); no chains, brands or trade marks (Swatch, Hallmark, Benefit, No7…) and no famous people, including first name + surname clashes (Kate + Moss); no innuendo; never "The {name}"; possessive before a trade word ("{name}'s Bakery"), except brand pages (streetwear, clothing, t-shirt, makeup, perfume, jewelry, soap, crochet) which may use "{name} Studios"; no Ltd/LLC/Inc; avoid UK/US spelling differences inside names.
- Page copy (article, description, seoTitle, seoKeywords, noun, nameSource) is written to the checklist in docs/HANDOVER.md "Content" and docs/CONTENT.md; keep it when changing a page's data, and recheck the article's example names afterwards. Meanings in name-list copy go in straight single quotes ('moon').
- Commit trailers: end commit messages with the Co-Authored-By and Claude-Session lines the harness gives. Pull before building; merge, never rebase or force-push.

- Site Jobs: when you finish work that leaves something for Richard to do, or completes a job, update the Site Jobs page (https://claude.ai/artifact/9cukbteXbK5sJbHyxGHPri) with ArtifactData in the `tasks` collection: add new jobs with urgency and importance (1–5) and score = urgency × importance, tick done ones, and never delete or untick.
